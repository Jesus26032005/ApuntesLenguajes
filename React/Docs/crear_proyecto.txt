# Pasos para Crear y Poner en Marcha un Proyecto de React

Esta guía te mostrará cómo crear una nueva aplicación de React desde cero y cómo ejecutarla en tu máquina local.

## 1. Prerrequisitos

Antes de comenzar, asegúrate de tener instalado lo siguiente en tu sistema:

- **Node.js:** React necesita Node.js para funcionar. Puedes descargarlo e instalarlo desde [https://nodejs.org/](https://nodejs.org/). Al instalar Node.js, también se instalará **npm** (Node Package Manager), que es el gestor de paquetes que usaremos.

Puedes verificar si los tienes instalados ejecutando los siguientes comandos en tu terminal:
` ` `
node -v
npm -v
` ` `
Estos comandos deberían mostrarte las versiones que tienes instaladas.

## 2. Creación del Proyecto (Usando Vite - Recomendado)

Vite es una herramienta moderna y extremadamente rápida para crear proyectos web. Es la opción recomendada actualmente para iniciar un proyecto de React.

1.  **Abre tu terminal** en la carpeta donde quieras crear tu proyecto.

2.  **Ejecuta el siguiente comando** para crear un nuevo proyecto de React con Vite. Reemplaza `nombre-de-tu-proyecto` con el nombre que desees.

    ` ` `bash
    npm create vite nombre-de-tu-proyecto -- --template react
    ` ` `

3.  **Sigue las instrucciones en pantalla.** Vite te preguntará si quieres usar TypeScript, a lo que puedes responder que sí o que no. Para un proyecto básico de JavaScript, simplemente elige "React" y luego "JavaScript".

## 3. Creación del Proyecto (Alternativa - Usando Create React App)

Create React App (CRA) es la forma tradicional de crear aplicaciones de React. Aunque es más lento que Vite, sigue siendo muy utilizado.

1.  **Abre tu terminal** en la carpeta donde quieras crear tu proyecto.

2.  **Ejecuta el siguiente comando.** Reemplaza `nombre-de-tu-proyecto` con el nombre que desees.

    ` ` `bash
    npx create-react-app nombre-de-tu-proyecto
    ` ` `
    Este comando creará una nueva carpeta con el nombre de tu proyecto y descargará todas las dependencias necesarias. Puede tardar unos minutos.

## 4. Poner en Marcha el Proyecto

Una vez que el proyecto ha sido creado (con Vite o Create React App), sigue estos pasos:

1.  **Navega a la carpeta de tu proyecto:**

    ` ` `bash
    cd nombre-de-tu-proyecto
    ` ` `

2.  **Instala las dependencias:**
    (Este paso es automático con Create React App, pero es bueno saberlo. Con Vite, es necesario).

    ` ` `bash
    npm install
    ` ` `

3.  **Inicia el servidor de desarrollo:**

    ` ` `bash
    npm run dev
    ` ` `
    *Nota: Si usaste Create React App, el comando es `npm start`.*

    Este comando compilará la aplicación e iniciará un servidor de desarrollo local. La terminal te mostrará la dirección URL donde puedes ver tu aplicación, generalmente `http://localhost:5173` (para Vite) o `http://localhost:3000` (para Create React App).

## 5. Ver tu Aplicación

Abre tu navegador web y ve a la dirección que te indicó la terminal (por ejemplo, `http://localhost:5173`). Deberías ver la página de inicio de tu nueva aplicación de React.

¡Felicidades! Has creado y puesto en marcha tu primer proyecto de React. Cualquier cambio que hagas en los archivos de código fuente (dentro de la carpeta `src`) se reflejará automáticamente en el navegador.

## 6. Crear una Versión para Producción

Cuando estés listo para desplegar tu aplicación en un servidor real, necesitarás crear una versión optimizada para producción. Para ello, detén el servidor de desarrollo (con `Ctrl + C`) y ejecuta:

` ` `bash
npm run build
` ` `

Este comando creará una carpeta `dist` (o `build` si usas Create React App) con los archivos estáticos de tu aplicación, listos para ser subidos a un servicio de hosting.
